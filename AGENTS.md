# AGENTS.md

Directus interface extension: Prev/Next navigation buttons on item edit pages,
so users move between items of a collection without returning to the list.
Built as a Directus extension with `@directus/extensions-sdk`.

## Commands

- `npm install`
- `npm run build`: production build to `dist/`.
- `npm run dev`: watch mode, no minify.
- `./deploy.sh`: local helper, ignored by git. Update only if asked.
- No lint and no tests are configured. If you add them, add `npm run lint` /
  `npm test` scripts and document a single-test command here.

## Release and dist

- `dist/` is generated by CI. Do not edit it by hand.
- Release = entry in CHANGELOG.md + tag `vX.Y.Z`.
- Avoid touching `package-lock.json` unless dependencies change.

## Architecture

- `src/index.ts`: registers the interface via `defineInterface`.
  - id `item-navigation`, types `['alias']` (virtual field, no column),
    localTypes `['presentation']`, group `presentation`.
  - Options: `sortField` (string, default `''`, auto-detects `sort` or the
    primary key), `sortDirection` (`'asc'` or `'desc'`, default `'asc'`),
    `showLabels` (boolean, default `true`).
- `src/interface.vue`: Vue SFC with navigation logic and styles.
  - Props: `collection`, `primaryKey`, `sortField?`, `sortDirection?`,
    `showLabels?`.
  - State: `loading`, `prevId`, `nextId`, `position` (`{ current, total }`).
  - `fetchNavigation()` queries prev/next and position, `navigateTo(id)` uses
    Vue Router, `t(key)` is the inline i18n.

### Navigation algorithm

1. Read the current item's sort field value.
2. Prev: items with sort value less than current, nearest one.
3. Next: items with sort value greater than current, nearest one.
4. Position: count of items before the current one.
5. Both ascending and descending directions are supported.

```text
GET /items/{collection}?filter[sort][_lt]={value}&sort=-sort&limit=1
GET /items/{collection}?filter[sort][_gt]={value}&sort=sort&limit=1
GET /items/{collection}?filter[sort][_lt]={value}&aggregate[count]=*
```

When changing queries, verify the `position` math for both directions.

## Code style

- Indent with tabs (as in `src/index.ts` and `src/interface.vue`).
- Single quotes, semicolons, trailing commas in multiline literals.
- ES module imports; order: third-party, Directus SDK, local files.
- `const`/`let`, explicit unions for IDs (`string | number | null`),
  `interface` for props, minimal type assertions.
- Vue: `<script setup lang="ts">`, state in `ref`/`computed`, refresh via
  `watch` + `onMounted`, no side effects in computed, declarative templates.
- Naming: camelCase variables and functions, PascalCase components,
  kebab-case CSS classes.

## Directus API, routing, errors

- HTTP via `useApi()`, collection fields via `useStores()`.
- Filter and sort through API params (`filter`, `sort`, `limit`), request
  only needed fields.
- Routing via `useRoute()` / `useRouter()`, paths `/content/{collection}/{id}`.
- Wrap async calls in `try/catch/finally`, log with a short prefix
  (`Navigation fetch error`), always reset `loading` in `finally`.

## UI

- Directus theme variables only, no hard-coded colors: `--theme--border-color`,
  `--theme--border-radius`, `--theme--background`, `--theme--foreground`,
  `--theme--foreground-subdued`, `--theme--primary`,
  `--theme--background-accent`. Styles stay `scoped` in the SFC.
- Labels: English "Prev" / "Next", Russian "Назад" / "Далее", chosen by
  `navigator.language`. New keys go into the same translation map.
- Keep buttons disabled via `:disabled` and `.disabled`; new controls need text
  or `aria-label`. Keep loading state accurate to prevent rapid clicks.

## Usage

1. Add a field of type Alias to the collection.
2. Select the interface Item Navigation.
3. Set the sort field if needed (default `sort` or primary key).
4. Put the field at the top of the form.

## Change checklist

- Navigation still works for ascending and descending sort.
- Auto-detect of `sort` or primary key is preserved.
- `showLabels` behavior is unchanged.
- When adding options, update `src/index.ts` and prop defaults.
- Run `npm run build` before shipping; update README and CHANGELOG if behavior
